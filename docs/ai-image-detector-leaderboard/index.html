Reproduce every number locally in one command

No private files and no manual dataset downloads. The standalone PEP 723 script streams all 578 pinned files over HTTP byte-ranges, verifies SHA-256 deduplication, warms each model on CPU, and writes the full JSON report.

uv run https://huggingface.co/wiltodelta/raiw-source-classify/resolve/main/benchmark.py --json-out benchmark_results.json
  • Zero training overlap: all 578 SHA-256 file hashes are verified disjoint against every training, calibration, and test hash of raiw-source-classify.
  • Scope boundary: pixel-pipeline attribution is distinct from cryptographic provenance (C2PA, SynthID, vendor metadata), which is handled deterministically by remove-ai-watermarks identify.

Submit an open-weights detector

Any public checkpoint on Hugging Face Hub with reproducible inference code and a declared license can be added to this matrix.

  • 1. Pin an immutable commit SHA for your model repository on Hugging Face Hub.
  • 2. Add an evaluator to benchmark.py using your model card's documented preprocessing and threshold (no test-set threshold tuning on the 578 benchmark files).
  • 3. Open a discussion or pull request on wiltodelta/raiw-source-classify or GitHub Issues with the resulting JSON output.
